## Scientific Publications

### Power2Picture: Neural Network Accelerator Security

**Co-Author** | IEEE FCCM 2023
[Paper on IEEE Xplore](https://ieeexplore.ieee.org/document/10171482)

Research on reconstructing input data from Neural Network Accelerators through Power Side-Channel Analysis. The work demonstrates how Generative CNNs can be used to reconstruct original data from power consumption patterns of FPGAs.

Key insight: Even with correct encryption and secure software implementation, hardware behavior can create security vulnerabilities. Hardware Security is an essential component of holistic security concepts.
